Assignment 22 - Pattern Printing Programs in C

This repository contains five C programs to practice character and number pattern printing using loops, conditional statements and arithmetic operations.

Programs Included:

1) Display an Increasing Alphabet Pattern

Accept a number from the user and display an increasing alphabet pattern starting from 'A'.

Example:

    Input:  iNo = 5
    Output:  A   B   C   D   E

2) Display a Decreasing Number Pattern with '#'

Accept a number from the user and display a decreasing number pattern with '#' character after each number.

Example:

    Input:  iNo = 5
    Output:  5   #   4   #   3   #   2   #   1   #

3) Display an Increasing Number Pattern with '*'

Accept a number from the user and display an increasing number pattern with '*' character after each number.

Example:

    Input:  iNo = 5
    Output:  1   *   2   *   3   *   4   *   5   *

4) Display an Increasing Number Pattern with '#' and '*'

Accept a number from the user and display an increasing number pattern with '#' before and '*' after each number.

Example:

    Input:  iNo = 4
    Output:  #   1   *   #   2   *   #   3   *   #   4   *

5) Display First N Even Numbers

Accept a number from the user and display the first N even numbers.

Example:

    Input:  iNo = 8
    Output:  2   4   6   8   10   12   14   16


How to Compile

Open Command Prompt and navigate to the program folder.

Use the following GCC commands to compile each program:

gcc Program22_1.c -o Myexe
gcc Program22_2.c -o Myexe
gcc Program22_3.c -o Myexe
gcc Program22_4.c -o Myexe
gcc Program22_5.c -o Myexe


How to Run

After successful compilation, execute the program using:

Myexe

Note: Compile and run one program at a time. The '-o Myexe' option specifies the name of the executable file.
