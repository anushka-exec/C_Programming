Assignment 23 - String Manipulation Programs in C

This repository contains five C programs to practice string manipulation using character-based operations, conditional statements and loops.


Programs Included:

1) Convert a String into Lowercase
Accept a string from the user and convert all uppercase characters into lowercase.

Example:

    Input:      Marvellous Multi OS
    Output:     marvellous multi os

2) Convert a String into Uppercase
Accept a string from the user and convert all lowercase characters into uppercase.

Example:

    Input:      Marvellous Multi OS
    Output:     MARVELLOUS MULTI OS

3) Toggle the Case of Each Character in a String
Accept a string from the user and toggle the case of each character. Convert uppercase characters into lowercase and lowercase characters into uppercase.

Example:

    Input:      Marvellous Multi OS
    Output:     mARVELLOUS mULTI os

4) Display Only Digits from a String
Accept a string from the user and display only the numeric digits present in that string.

Example:

    Input:      marve89llous121
    Output:     89121

    Input:      Demo
    Output:     ----

5) Count the Number of White Spaces in a String
Accept a string from the user and count the total number of white spaces present in the string.

Example:

    Input:      MarvellouS
    Output:     0

    Input:      MarvellouS Infosystems
    Output:     1


How to Compile and Run:

Open Command Prompt and navigate to the Assignment_23 folder.

Use the following GCC commands to compile each program:

gcc Program23_1.c -o Myexe
gcc Program23_2.c -o Myexe
gcc Program23_3.c -o Myexe
gcc Program23_4.c -o Myexe
gcc Program23_5.c -o Myexe

Run the executable using:

On Windows:         Myexe

On Linux / macOS:   ./Myexe

Note: Compile and run each program separately.
