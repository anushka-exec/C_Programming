Assignment 14 – Factor-Based Programs in C

This repository contains various C programs written to practice fundamental programming concepts such as loops, conditional statements, arithmetic operations, and factor manipulation.

Programs Included

1) Accept a number from the user and display the multiplication of all its factors.

2) Accept a number from the user and display all its factors in decreasing order.

3) Accept a number from the user and display all its non-factors.

4) Accept a number from the user and return the summation of all its non-factors.

5) Accept a number from the user and return the difference between the summation of all its factors and non-factors.


How to Compile

Open Command Prompt and navigate to the program folder.

Use the following GCC commands to compile each program:

gcc Program14_1.c -o Myexe
gcc Program14_2.c -o Myexe
gcc Program14_3.c -o Myexe
gcc Program14_4.c -o Myexe
gcc Program14_5.c -o Myexe


How to Run

After successful compilation, execute the program using:

Myexe

Note: Compile and run one program at a time. The '-o Myexe' option specifies the name of the executable file.
