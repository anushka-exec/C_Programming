Assignment 11 – Range-Based Programs in C

This repository contains various C programs written to practice fundamental programming concepts such as loops, conditional statements, range operations, and number manipulation.

Programs Included

1) Accept a range from the user and display all numbers between the given range.

2) Accept a range from the user and display all even numbers between the given range.

3) Accept a range from the user and return the addition of all numbers between the given range. (The range should contain positive numbers only.)

4) Accept a range from the user and return the addition of all even numbers between the given range. (The range should contain positive numbers only.)

5) Accept a range from the user and display all numbers between the given range in reverse order.

How to Compile

Open Command Prompt and navigate to the program folder.

Use the following GCC commands to compile each program:

gcc Program11_1.c -o Myexe
gcc Program11_2.c -o Myexe
gcc Program11_3.c -o Myexe
gcc Program11_4.c -o Myexe
gcc Program11_5.c -o Myexe


How to Run

After successful compilation, execute the program using:

Myexe

Note: Compile and run one program at a time. The '-o Myexe' option specifies the name of the executable file.
