Assignment 15 – Basic C Programming Programs

This repository contains various C programs written to practice fundamental programming concepts such as input/output operations, conditional statements, arithmetic operations, and basic calculations.

Programs Included

1) Accept a name from the user and display that name.

2) Accept a number from the user and check whether it is greater than 100 or not.

3) Accept two numbers from the user and check whether they are equal or not.

4) Accept three numbers from the user and print their multiplication.

5) Accept total marks and obtained marks from the user and calculate the percentage.


How to Compile

Open Command Prompt and navigate to the program folder.

Use the following GCC commands to compile each program:

gcc Program15_1.c -o Myexe
gcc Program15_2.c -o Myexe
gcc Program15_3.c -o Myexe
gcc Program15_4.c -o Myexe
gcc Program15_5.c -o Myexe


How to Run

After successful compilation, execute the program using:

Myexe

Note: Compile and run one program at a time. The '-o Myexe' option specifies the name of the executable file.
