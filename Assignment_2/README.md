Programs Included :
1) Accept a number from the user and display the '*' character that many times.
2) Accept a number from the user and generate a simple '*' pattern based on the entered value.
3) Accept a number from the user and display "Hello" if the number is less than 10; otherwise, display "Demo".
4) Accept two numbers from the user and display the first number repeatedly according to the value of the second number.
5) Accept a number from the user and determine whether it is even or odd.

How to Compile :
Open Command Prompt and navigate to the program folder.

gcc ProgramName.c -o Myexe
Example:

gcc Program2_1.c -o Myexe
gcc Program2_2.c -o Myexe
gcc Program2_3.c -o Myexe
gcc Program2_4.c -o Myexe
gcc Program2_5.c -o Myexe

How to Run :
Myexe
