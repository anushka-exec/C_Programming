This repository contains various C programs written to practice fundamental programming concepts such as conditional statements, loops, operators, functions, and number manipulation.

Programs Included
1) Display a pattern using '*' and '#' characters based on the user-input number.
2) Convert US Dollars (USD) to Indian Rupees (INR).
3) Calculate the even factorial of a given number.
4) Calculate the odd factorial of a given number.
5) Find the difference between the even factorial and odd factorial of a given number.

How to Compile :
Open Command Prompt and navigate to the program folder.

gcc ProgramName.c -o Myexe
Example:

gcc Program9_1.c -o Myexe
gcc Program9_2.c -o Myexe
gcc Program9_3.c -o Myexe
gcc Program9_4.c -o Myexe
gcc Program9_5.c -o Myexe

How to Run :
Myexe
