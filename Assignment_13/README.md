Assignment 13 – Digit Manipulation Programs in C

This repository contains various C programs written to practice fundamental programming concepts such as loops, conditional statements, arithmetic operations, and digit manipulation.

Programs Included

1) Accept a number from the user and return the count of even digits in it.

2) Accept a number from the user and return the count of odd digits in it.

3) Accept a number from the user and return the count of digits between 3 and 7.

4) Accept a number from the user and return the multiplication of all its digits.

5) Accept a number from the user and return the difference between the summation of even digits and the summation of odd digits.


How to Compile

Open Command Prompt and navigate to the program folder.

Use the following GCC commands to compile each program:

gcc Program13_1.c -o Myexe
gcc Program13_2.c -o Myexe
gcc Program13_3.c -o Myexe
gcc Program13_4.c -o Myexe
gcc Program13_5.c -o Myexe


How to Run

After successful compilation, execute the program using:

Myexe

Note: Compile and run one program at a time. The '-o Myexe' option specifies the name of the executable file.
