This repository contains various C programs written to practice fundamental programming concepts such as loops, functions, operators, conditional statements, and pattern printing.

Programs Included :
1) Accept a number from the user and display the specified count of even numbers.
2) Accept a number from the user and display all even factors of the given number.
3) Accept a number from the user and identify its even factors using iteration and conditional logic.
4) Accept a character from the user and convert it to the opposite case (uppercase to lowercase or lowercase to uppercase).
5) Accept a character from the user and determine whether it is a vowel or a consonant.

How to Compile :
Open Command Prompt and navigate to the program folder.

gcc ProgramName.c -o Myexe
Example:

gcc Program3_1.c -o Myexe
gcc Program3_2.c -o Myexe
gcc Program3_3.c -o Myexe
gcc Program3_4.c -o Myexe
gcc Program3_5.c -o Myexe

How to Run :
Myexe
