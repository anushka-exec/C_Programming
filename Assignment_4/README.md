This repository contains various C programs written to practice fundamental programming concepts such as loops, functions, operators, conditional statements, and pattern printing.

Programs Included :
1) Determine whether a given number is positive or negative.
2) Check whether a number is even or odd.
3) Compare two numbers and identify the greater value.
4) Verify a user's voting eligibility based on age criteria.
5) Check whether a number is divisible by 5.

How to Compile :
Open Command Prompt and navigate to the program folder.

gcc ProgramName.c -o Myexe
Example:

gcc Program4_1.c -o Myexe
gcc Program4_2.c -o Myexe
gcc Program4_3.c -o Myexe
gcc Program4_4.c -o Myexe
gcc Program4_5.c -o Myexe

How to Run :
Myexe
