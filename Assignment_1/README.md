Programs Included :
1) Division of two numbers
2) Print 5 times "Marvellous" on screen
3) Print numbers from 5 to 1
4) Check whether a number is divisible by 5
5) Print '*' N times

How to Compile :
Open Command Prompt and navigate to the program folder.

gcc ProgramName.c -o Myexe
Example:

gcc Program1_1.c -o Myexe
gcc Program1_2.c -o Myexe
gcc Program1_3.c -o Myexe
gcc Program1_4.c -o Myexe
gcc Program1_5.c -o Myexe

How to Run :
Myexe
