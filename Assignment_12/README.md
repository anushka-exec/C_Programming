Assignment 12 – Digit Manipulation Programs in C

This repository contains various C programs written to practice fundamental programming concepts such as loops, conditional statements, and digit manipulation.

Programs Included

1) Accept a number from the user and display its digits in reverse order.

2) Accept a number from the user and check whether it contains the digit 0 or not.

3) Accept a number from the user and count the frequency of digit 2 in it.

4) Accept a number from the user and count the frequency of digit 4 in it.

5) Accept a number from the user and count the frequency of digits that are less than 6.


How to Compile

Open Command Prompt and navigate to the program folder.

Use the following GCC commands to compile each program:

gcc Program12_1.c -o Myexe
gcc Program12_2.c -o Myexe
gcc Program12_3.c -o Myexe
gcc Program12_4.c -o Myexe
gcc Program12_5.c -o Myexe


How to Run

After successful compilation, execute the program using:

Myexe

Note: Compile and run one program at a time. The '-o Myexe' option specifies the name of the executable file.
